# Mac চালু হচ্ছে না + স্ক্রিনে সমস্যা — ধাপে ধাপে সমাধান

**অবস্থা:** MacBook Pro 2017, OpenCore Legacy Patcher (OCLP) দিয়ে macOS Sequoia বসানো, পাশে Windows (Boot Camp)।
এখন কোনোটাই চালু হয় না, চালু হতে গেলে এরর আসে, আর স্ক্রিনেও সমস্যা। আগে অনেক গরম হতো।

## আগে সত্যিটা জেনে নিন
**Windows আর macOS দুটোই** একসাথে নষ্ট হওয়া আর তার সাথে **স্ক্রিনের সমস্যা ও অতিরিক্ত গরম** — এই তিনটা একসাথে
হলে বেশিরভাগ ক্ষেত্রে কারণ **হার্ডওয়্যার**, সফটওয়্যার না:

- **15" মডেল (AMD Radeon Pro 555/560 গ্রাফিক্স):** গরমে AMD গ্রাফিক্স চিপ বা তার সোল্ডার নষ্ট হয়ে যায়।
  তখন স্ক্রিনে দাগ পড়ে বা স্ক্রিন কালো হয়ে যায়, আর যেকোনো OS চালু হতে গিয়ে crash করে।
- **ডিসপ্লে ক্যাবল ("Flexgate"):** স্ক্রিনের নিচে স্টেজ-লাইটের মতো আলো দেখা যায়, অথবা ঢাকনা একটু খুললেই স্ক্রিন বন্ধ হয়ে যায়।
- **SSD নষ্ট হওয়া:** দুটো OS-ই একই ডিস্কে থাকে, তাই ডিস্ক নষ্ট হলে দুটোই চালু হয় না।

কোনো স্ক্রিপ্ট দিয়েই হার্ডওয়্যার ঠিক করা যায় না। MacDoctor যা পারে: **কারণ নিশ্চিত করা, আপনার ফাইল বাঁচানো,
আর সফটওয়্যারের সমস্যা হলে সেটা ঠিক করা।** নিচের ক্রম মেনে চলুন:

---

### ধাপ ১ — SMC ও NVRAM রিসেট (২ মিনিট, ক্ষতি নেই)
1. Mac বন্ধ করুন। বাম **Shift + Control + Option** আর **পাওয়ার বাটন** ১০ সেকেন্ড চেপে ধরে রাখুন, তারপর ছেড়ে দিন।
2. চালু করেই **Option + Command + P + R** ২০ সেকেন্ড চেপে ধরে রাখুন।
   - এতে OCLP-র NVRAM সেটিং মুছে যায়, তাই Sequoia চালু না-ও হতে পারে। এটা স্বাভাবিক, এতে কোনো ক্ষতি হয় না।

### ধাপ ২ — বাইরের মনিটর দিয়ে পরীক্ষা (স্ক্রিনের সমস্যা কোথায়?)
USB-C থেকে HDMI অ্যাডাপ্টার দিয়ে একটি টিভি বা মনিটর লাগান।
| ফলাফল | মানে |
|---|---|
| বাইরের মনিটরে সব ঠিক, শুধু ল্যাপটপের স্ক্রিনে সমস্যা | ডিসপ্লে বা ডিসপ্লে ক্যাবল নষ্ট (GPU ঠিক আছে) |
| বাইরের মনিটরেও দাগ বা অদ্ভুত রং | **গ্রাফিক্স চিপ (GPU) / লজিক বোর্ড** নষ্ট |

### ধাপ ৩ — Apple Diagnostics (হার্ডওয়্যার টেস্ট)
Mac বন্ধ করুন → চালু করেই **D** চেপে ধরে রাখুন → টেস্ট শেষ হলে একটা কোড দেখাবে (যেমন `VFD006`, `PPT004`)।
কোডটা লিখে রাখুন বা ছবি তুলে রাখুন। `VFD…` মানে ডিসপ্লে/GPU, `PPT…` মানে ব্যাটারি, `NDD…` মানে USB/ট্র্যাকপ্যাড।

### ধাপ ৪ — কোনো OS সরাসরি চালু হয় কিনা
চালু করেই **Option** চেপে ধরে রাখুন। স্টার্টআপ ডিস্কের তালিকা এলে:
- **Windows** বেছে নিন। এতে OpenCore বাদ দিয়ে সরাসরি চালু হয়।
- Windows-ও যদি নীল স্ক্রিন বা crash দেখায়, তাহলে সমস্যা প্রায় নিশ্চিতভাবে হার্ডওয়্যারে।

### ধাপ ৫ — Internet Recovery + MacDoctor Recovery
OCLP-র Sequoia-র নিজের Recovery সাধারণত OpenCore ছাড়া কাজ করে না। তাই **Internet Recovery** ব্যবহার করুন:
1. USB (MACDOCTOR) লাগান, Wi-Fi পাশে রাখুন।
2. চালু করেই **Option + Command + R** চেপে ধরে রাখুন। ঘুরন্ত গ্লোব দেখা গেলে ছেড়ে দিন। এটা Apple-এর অফিসিয়াল Ventura Recovery।
3. **Utilities → Terminal** খুলে লিখুন:
   ```sh
   sh /Volumes/MACDOCTOR/recovery/recovery-repair.sh
   ```
4. এই ক্রমে অপশন চালান:
   - **6** — crash-এর কারণ বের করবে। এটা বলে দেবে সমস্যা GPU, SSD, গরম নাকি OCLP প্যাচের।
   - **8** — Windows পার্টিশন, OpenCore আর NVRAM-এর অবস্থা দেখাবে।
   - **1** — ডিস্ক মেরামত (First Aid)।
   - **2** — জরুরি ফাইল USB-তে ব্যাকআপ (**সবার আগে এটা করে নিন!**)।
   - **7** — (শুধু 15" মডেলে) Intel গ্রাফিক্স দিয়ে চালু করে দেখা। এতে Mac চালু হলে নিশ্চিত হওয়া যায় যে AMD GPU নষ্ট।
   - সব রিপোর্ট USB-এর `reports` ফোল্ডারে সেভ হয়। পরে কাউকে দেখাতে পারবেন।

### ধাপ ৬ — সফটওয়্যারের সমস্যা হলে: পরিষ্কার করে Ventura বসান
হার্ডওয়্যার ঠিক থাকলে, অর্থাৎ Diagnostics-এ কোনো কোড আসেনি আর অপশন 6 OCLP দেখিয়েছে:
1. প্রথমে ফাইলের ব্যাকআপ নিন (অপশন 2)।
2. Internet Recovery → **Disk Utility** → View → Show All Devices → পুরো ডিস্ক (APPLE SSD) → **Erase**
   (Format: APFS, Scheme: GUID)। ⚠️ এতে macOS আর Windows দুটোই মুছে যাবে।
3. **Reinstall macOS** → Apple-এর অফিসিয়াল **Ventura** বসান। এই Mac-এর জন্য এটাই সবচেয়ে স্থিতিশীল।
4. Ventura চালু হলে USB থেকে `MacDoctor.command` চালিয়ে দেখে নিন সব ঠিক আছে কিনা।
5. Windows দরকার হলে পরে Boot Camp Assistant দিয়ে আবার বসাতে পারবেন।
   গরম কমাতে Sequoia/OCLP আর বসাবেন না, এটা এই Mac-কে বেশি চাপ দেয়।

### ধাপ ৭ — হার্ডওয়্যারের সমস্যা হলে
- GPU বা লজিক বোর্ড: সার্ভিস সেন্টারে **লজিক বোর্ড রিপেয়ার/রিবল (GPU reball)** বা বোর্ড বদলানোর কথা জিজ্ঞেস করুন।
- ডিসপ্লে ক্যাবল (Flexgate): শুধু ক্যাবল বদলেই অনেক সময় ঠিক হয়, পুরো স্ক্রিন বদলানো লাগে না।
- গরম কমাতে: ফ্যান আর হিটসিঙ্ক পরিষ্কার করান, থার্মাল পেস্ট বদলান।
- সার্ভিস সেন্টারে নেওয়ার আগে অপশন 2 দিয়ে ফাইলের ব্যাকআপ নিয়ে নিন।
