# MacBook Pro 2017 — জরুরি কী-কম্বিনেশন

এই কাজগুলো কোনো স্ক্রিপ্ট করতে পারে না, কারণ এগুলো Mac চালু হওয়ার মুহূর্তে কীবোর্ড দিয়ে করতে হয়।
(MacBook Pro 2017-এ T2 চিপ নেই, তাই নিচের নিয়মগুলোই প্রযোজ্য।)

| কাজ | কখন দরকার | কীভাবে |
|---|---|---|
| **SMC রিসেট** | ফ্যান সারাক্ষণ জোরে চলে, চার্জ হয় না, ঘুম থেকে জাগে না, kernel_task বেশি CPU নেয় | Mac বন্ধ করুন → বাম **Shift + Control + Option** আর **পাওয়ার বাটন** একসাথে ১০ সেকেন্ড চেপে ধরুন → সব ছেড়ে দিন → সাধারণভাবে চালু করুন |
| **NVRAM রিসেট** | ভুল স্টার্টআপ ডিস্ক, শব্দ/ডিসপ্লে/সময় অঞ্চল ভুল, Wi-Fi হারিয়ে যায় | চালু করেই সাথে সাথে **Option + Command + P + R** ২০ সেকেন্ড চেপে ধরুন |
| **Safe Mode** | চালু হতে আটকে যায়, কোনো অ্যাপ বারবার ক্র্যাশ করে | চালু করেই **Shift** চেপে ধরুন, লগইন স্ক্রিন এলে ছাড়ুন। Safe Mode-এ cache পরিষ্কার হয় ও থার্ড-পার্টি প্রোগ্রাম বন্ধ থাকে |
| **Recovery Mode** | ডিস্ক মেরামত, macOS রিইনস্টল, MacDoctor Recovery স্ক্রিপ্ট | চালু করেই **Command + R** |
| **Internet Recovery** | সাধারণ Recovery কাজ না করলে | চালু করেই **Option + Command + R** (Wi-Fi লাগবে) |
| **Apple Diagnostics** | হার্ডওয়্যার (RAM, লজিক বোর্ড, ব্যাটারি) পরীক্ষা | চালু করেই **D** চেপে ধরুন |
| **স্টার্টআপ ডিস্ক বাছাই** | USB/বাইরের ডিস্ক থেকে চালু করতে | চালু করেই **Option** চেপে ধরুন |
| **Target Disk Mode** | আরেকটি Mac থেকে এই Mac-এর ফাইল উদ্ধার | Thunderbolt 3 (USB-C) ক্যাবল দিয়ে দুটি Mac যুক্ত করে চালু করেই **T** চেপে ধরুন — অন্য Mac-এ এই Mac-এর ডিস্ক দেখাবে |
